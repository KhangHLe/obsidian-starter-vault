## Creating a new task

Click ![[Add Task Button.png]] on any of the task pages or use the keyboard shortcut `Ctrl + Alt + N`to create a new task. Select the time desired for the task

> [!tip]
> Alternatively, you can also Reschedule (see below) to convert any existing note into a task note.

## Rescheduling

Use the keyboard shortcut `Ctrl + R` to reschedule the current open task page.

## Recurrence

Add the property `repeats` to the task page. The syntax looks like this: `every x days/weeks/months`. When the task is checked / toggled done, instead of closing the task, the scheduled and deadline properties will add the recurring durations.

## Marking task as done

You can click on any of the task checkbox in any of the task pages, or you can use the keyboard shortcut `Ctrl + Space` to close the current task page as done.

## Deadlines

You can the property `deadline` and it will show up accordingly on the task pages.

## Phone Notifications (Android)

Download the app Notifian on Google Play and scan your vault. Add `reminds on` property to any pages to have notifications show up
